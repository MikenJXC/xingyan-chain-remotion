# 《星研链：一颗证据核心的旅程》

一间深蓝色的科研实验室里，地面中央只有一条向远处延伸的电蓝轨道。空间克制、安静，金属表面只有少量冷光反射。半空中，一颗蓝色球体从高处落下。它不是标志，也不是装饰，而是一颗尚未装入任何依据的“研究核心”。

球体受到重力作用不断加速，撞上轨道。撞击没有被剪掉：球体压低、回弹，能量沿地面扩散成一圈冲击波。冲击波掀起四周散落的十块研究卡片。卡片在空中翻转，有的互相遮挡，有的偏离轨道，代表轻易生成却缺乏判断依据的选题。球体第二次落下时，其中一块卡片被蓝光捕获，顺着球体运动的方向被吸入核心。其余卡片失去能量，落回地面。核心第一次发亮，也因此获得继续前进的动力。

球体沿轨道向前滚动。它不是突然进入下一幕，而是亲自抵达下一段空间。轨道两侧依次排列着研究对象、研究目标、时间、算力、数据和风险偏好六个条件模块。球体靠近哪个模块，哪个模块就被磁力拉起，绕球体转动一圈，再嵌入核心外层。六个条件全部装配完成后，核心的运动更加稳定，前方的第一道门才被点亮。

轨道上竖着四道实体门：检索、去重、核验、编号。球体依靠之前获得的速度依次穿过它们。每穿过一道门，门框会受到碰撞产生轻微震动，并在球体周围留下一个发光节点。第二道门过滤掉重复节点，第三道门让无效节点坠落，第四道门将剩余节点固定成有序证据链。最后一道门释放出的能量沿轨道继续向前，撞入一座尚未启动的评分台。

评分台上的五根立柱由这次撞击依次升起。每根立柱代表一个研究方向，高度对应统一尺度下的总分。球体悬停在五根立柱中央，把自身携带的证据节点投射到所有立柱上。随后三道红色实体闸门从上方落下：证据不足的高度被压低，资源未确认的高度被压低，依赖额外条件的高度再次被压低。闸门抬起后，第三根立柱仍然最高。球体因此落到第三根立柱顶部，完成优胜方案确认。

第三根立柱下沉，把球体重新送回轨道。球体继续前进，进入一个环形扫描器。扫描环从上到下掠过球体，检查候选完整性、证据数量、评分尺度和优胜结果是否一致。扫描通过后，数据集、开源代码和评测指标三个资源模块从轨道两侧飞来，与球体发生吸附。每吸附一个模块，球体就释放出一张报告页面。

四张报告页面不是凭空出现，而是从核心内部依次展开：候选方向对比、优胜方案设计、最小可行实验、证据与边界。最后一张页面停留得最久，上面明确提示：“本轮未发现，不等于不存在。”随后四张页面沿原来的轨迹折回，包裹并压缩成最初那颗蓝色球体。球体沿轨道缓缓升起，所有运动最终停止。

画面只剩下经过整条流程的证据核心，以及一句结论：

**星研链——先摆证据，再给结论。**

## 叙事原则

- 全片只有一个持续存在的主角：蓝色证据核心。
- 下一事件必须由上一事件的碰撞、惯性、磁力、能量传递或结构变化触发。
- 摄像机跟随核心移动，空间本身连续存在，不使用互不相关的场景切换。
- 字幕可以淡入淡出，实体物体不能无理由消失。
- 最终状态回到开场球体，但它已经携带完成整套流程后的意义，形成首尾闭环。
