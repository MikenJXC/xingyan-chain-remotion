# 物体运动与因果表

| 时间 | 主体状态 | 原因 | 直接结果 | 对下一阶段的影响 |
|---|---|---|---|---|
| 0.0—2.2s | 核心自由落体并撞击轨道 | 重力 | 产生压缩、回弹和地面冲击波 | 冲击波掀起研究卡片 |
| 2.2—5.5s | 十块卡片被掀起并翻转 | 撞击能量 | 卡片形成信息过载，一块进入核心捕获范围 | 被捕获卡片向核心移动 |
| 5.5—9.5s | 一块卡片被吸收，其余卡片落下 | 核心磁力与阻尼 | 核心亮度、质量感和旋转速度提升 | 核心获得沿轨道前进的动力 |
| 9.5—14.5s | 核心滚过六个条件模块 | 前进惯性与磁力 | 模块依次抬起、环绕并嵌入核心 | 条件完整后第一道门解锁 |
| 14.5—20.0s | 核心穿过四道证据门 | 轨道动能 | 门框震动，证据节点依次留下 | 最后一道门向评分台传递能量 |
| 20.0—23.5s | 五根评分柱依次升起 | 证据门传来的冲击能量 | 五个候选以高度呈现 | 进入统一尺度比较 |
| 23.5—28.5s | 三道规则闸门依次下降 | 规则系统启动 | 虚高立柱被压低 | 第三根立柱成为稳定优胜者 |
| 28.5—31.0s | 优胜立柱接住核心并下沉 | 评分结果锁定 | 核心重新回到轨道 | 核心被送入复核扫描器 |
| 31.0—34.0s | 扫描环穿过核心 | 程序复核启动 | 完整性、证据量、尺度和优胜一致性完成检查 | 资源模块获准接入 |
| 34.0—37.0s | 三个资源模块依次吸附 | 扫描通过 | 每次吸附释放一张报告页 | 四页报告完整展开 |
| 37.0—39.0s | 报告展示边界并折回 | 交付完成 | 页面压缩回核心 | 形成首尾一致的品牌实体 |
| 39.0—40.0s | 核心升起并停稳 | 全流程完成 | 品牌与口号出现 | 故事闭环 |
